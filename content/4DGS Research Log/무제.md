## EGGS에 가장 가까운 Ex4DGS 구조

EGGS를 충실히 따르려면 다음이 가장 가깝습니다.

```
position
→ MLP_cont
→ local latent와 결합
→ 속성별 작은 MLP
```

출력:

```
MLP_dc       → DC residual
MLP_rest     → SH Rest
MLP_scale    → scale residual
MLP_rotation → static rotation
MLP_opacity  → base opacity
```

직접 저장:

```
DC base
scale base
local latent
```

원본 유지:

```
xyz_disp
xyz_motion
rotation_motion
opacity_duration_center/var
temporal metadata
```

```
직접 저장:
- static xyz
- xyz_disp
- xyz_motion
- rotation
- rotation_motion
- temporal opacity parameters

새 표현:
- static latent
- dynamic latent
- shared appearance MLP

MLP 출력:
- features_dc
- features_rest
- scaling
- opacity
```
