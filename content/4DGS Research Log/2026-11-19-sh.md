# Local Feature
---
위치 기반 공유 표현
	기준 위치 = 변위 xyz_disp을 적용하지 않은 기존 xyz를 사용한다.
	
	구면 영역으로 사상한 뒤, 주파수 인코딩을 적용한다. 이는 연속 공간 특징으로 공유된다.

* 위치에서 생성되는 continuous feature = dim 6
* Gaussian마다 생성되는 local feature = dim 10
두 특징을 결합한 16 dim 표현으로 SH dc, rest 계수를 복원한다.

# SH
---
*EGGGS에서의 SH 표현과 압축을 그대로 차용한다.*

1. SH DC Net Presentation
```python
rgb = SH2RGB(_features_dc[:, 0])
yuv = RGB2YUV(rgb)
```
SH DC -> RGB -> YCbCr (파란색, 빨간색 계열 색차 성분)

```python
_features_dc_base: [N, 1]
```
Y만 새로운 Gaussian 별 파라미터로 정의한다.
(Cb, Cr <- MLP 생성)

2. MLP SH Compression
parameter structure
```
모든 Gaussian이 공유하는 MLP_cont
모든 Gaussian이 공유하는 MLP_dc
모든 Gaussian이 공유하는 MLP_rest

Gaussian별 Local Feature 10개
Gaussian별 Y Base 1개
```
학습 완료 후 3 MLP 파라미터를 FP16으로 변환하여 저장한다.


# Compression
---
### 1. Training Ex4DGS 
기존 명시적 SH 표현으로 정적, 동적 Gaussian을 학습한다. 시간 구간을 점진적으로 확장하고 Static Gaussian에서 Dynamic Gaussian을 추출한다.

### 2. MLP
1. `densify_until_iter=30,000`이후 Static Gaussian의 SH를 공유 MLP 기반 표현으로 교체
2. 기존 SH = luminance (밝기 성분) + local feature

### 3. Sub-vector Quantization
```
SH 계수
 └─ 공통 MLP 표현으로 압축

MLP 가중치
 └─ FP16으로 압축

Local Feature
 └─ SVQ로 압축

Y Base
 └─ SVQ로 압축
```
