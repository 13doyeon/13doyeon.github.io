# Compression for Static Gaussian Scale, Opacity, Rotation

> [[2026-11-19-sh|Comp Static SH]]에서 진행했던 압축 표현을 scale, opacity, rotation 의 나머지 속성 값에 대해서도 적용한다.

![[Drawing 2026-11-21 02.04.16.excalidraw]]


# Opacity
---
log로 표현 후, mlp -> sigmoid 적용 
```python
self._opacity_init = torch.tensor([
    [np.log(0.1 / (1 - 0.1))]
])

opacity = self.opacity_activation(
    self.mlp_opacity(space_feature).float()
    + self._opacity_init
)
```


# Scale
---
exponential 먼저 적용 후, scale base 생성
(세 축의 scale 평균)
```python
scaling_base = self.scaling_activation(
    self._scaling.detach()
).mean(dim=1, keepdim=True)

scaling_base = self.scaling_inverse_activation(
    scaling_base
)
```

MLP 적용 후, 최종 scale
```python
scaling = self.scaling_activation(
    scaling + scaling_base
)
```


# Rotation
---
identity quaternion을 기준으로 MLP가 residual quaternion 생성
```python
self._rotation_init = torch.tensor([
    [1.0, 0.0, 0.0, 0.0]
])

rotation = self.rotation_activation(
    self.mlp_rotation(space_feature).float()
    + self._rotation_init
)
```
