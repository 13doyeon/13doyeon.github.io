# Train Parameter
---
## 1. Parameter
`CGuassianModel`

| 속성       | Static                      | Dynamic                                          |
| -------- | --------------------------- | ------------------------------------------------ |
| Position | _xyz                        | _xyz_motion                                      |
| Rotation | _rotation                   | _rotation_motion                                 |
| Scale    | _scaling                    | _scaling_motion                                  |
| SH       | _feature_dc / _feature_rest | _feature_dc_motion / _feature_rest_motion        |
| Opacity  | _opacity                    | _opacity_motion                                  |
|          |                             | _opacity_duration_center / _opacity_duration_var |
| 변위       | _xyz_disp                   |                                                  |

## 2. point cloud

1. `create_from_pcd` 초기 point cloud를 읽으면 다음 파라미터만 생성한다.

```python
self._xyz          = nn.Parameter(...)
self._features_dc  = nn.Parameter(...)
self._features_rest = nn.Parameter(...)
self._scaling      = nn.Parameter(...)
self._rotation     = nn.Parameter(...)
self._opacity      = nn.Parameter(...)

self._xyz_disp = nn.Parameter(torch.zeros_like(self._xyz))
```

2. `get_static_xyz_at_t` 
```python
return self._xyz + self._xyz_disp * t / self.duration
```

## 3. Dynamic Gaussian
`extract_dynamic_points_from_static` : Dynamic Gaussian 추출

1. 변위 점수 계산 : 특정 조건을 만족하는 점을 동적으로 판단함
2. Static --> Dynamic 파라미터 이전
```python
new_features_dc_motion   = self._features_dc[mask]
new_features_rest_motion = self._features_rest[mask]
new_scaling_motion       = self._scaling[mask]
new_opacity_motion       = self._opacity[mask]
new_rotation_motion      = self._rotation[mask].unsqueeze(1).repeat(...)
```
3. position : _xyz_disp로 부터 시간축 퀘적을 만들어 keyframe 개수만큼 보간해 초기화한다.
```python
new_xyz_motion = interpolate(stack([
    _xyz - _xyz_disp * interval / max_dur,
    _xyz + _xyz_disp * (1 + interval / max_dur)
]), size=(keyframe_num, 1))
```
4. 정적 파라미터에서 점 제거, 동적 파라미터 집합 추가

## 4. Dynamic position & rotation
`get_dynamic_xyz_at_t` `get_dynamic_rotation_at_t`

```python
# dynamic points
t = t + self.time_shift
t_idx = t // self.interval
delta_t = (t % self.interval) / self.interval

# xyz
return self.interpolator(self._xyz_motion, t_idx, delta_t)
# rotation
return self.quat_interpolator(self._rotation_motion, t_idx, delta_t)   
```

def get_motion_opacity_at_t(self, t, training=False):
