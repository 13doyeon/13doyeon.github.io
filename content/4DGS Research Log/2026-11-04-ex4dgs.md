# Method
---
## 1. Static Gaussian
 static gaussaisn은 위치를 다음과 같이 표현한다.
$$
 \mu(t) = \mathbf{x} + t'\mathbf{d}, t' = \frac{t}{l} \in [0, 1]
 $$
 기준 위치에서 시간에 따른 이동을 표현한다. 이는 완전히 고정된 Gaussian을 뜻하는 것이 아닌, 선형 이동이 가능한 Gaussian 이다.
*변위 파라미터 d(학습 파라미터)에 따른 움직임 점수 계산하여 dynamic 결정한다*
(색상변화와 같은 다른 속성 변화는 감지하기 힘들다.)
## 2. Dynamic Gaussian
 카메라와 Gaussian의 거리 영향을 보정하여 이동량을 평가한 뒤, Position 변화량이 큰 상위 2%으로 Gaussian을 선정한다. Position, Rotation, Opacity를 처리한다.
![[Pasted image 20261105061657.png]]

### 2.1. Position: Cubic Hermite Interpolation
* Hermite Spline(에르미트 곡선) : 정규화된 구간 [1, 0] 상에서 두 개의 점과 두 개의 접선으로 정의됨.

$$\mu(t) = \text{CHip}(p_n, m_n, p_{n+1}, m_{n+1}; t')$$
CHip을 기반으로, 시간 $t$에서 $G_d$ 위치 $\mu$ 를 계산한다. 여기에서 $p_n$ 은 n번째 key frame에서의 Gaussian 위치이다. 이는 추가 요구 사항을 줄이면서도 복잡한 움직임에 대해 표현력 유지 가능하다.
key frame은 코드상, 10으로 정의되어 있다.

### 2.2. Rotation: Slerp
* Slerp : Quaternion 구면 보간
$$
q(t) = \text{Slerp}(r_n, r_{n+1}; t') \quad
$$
$r_n$ 은 $n$번째 key frame에서의 가우시안의 회전이다.

*Position & Rotation은 Key Frame 기반 보간*
### 2.3. Opacity: Temporal Opacity
다음과 같은 3가지 경우로 나누어, 하나의 가우시안은 객체의 등장을 처리 + 다른 하나는 소멸 관리한다. 
* Appearance : 불투명도 객체가 나타날 때
* Visible : 객체 유지될 때
* Disappearance : 객체가 사라질 때
![[Pasted image 20261105061735.png]]

#### Temporal Opacity Code
처음 Static Gaussian으로 학습하다가, 움직임 조건을 충족한 Gaussian을 Dynamic Gaussian으로 전환한다.
**학습 파라미터**
* opacity motion : 기본 Opacity의 활성화 전 값
* opacity duration center : 불투명도를 유지할 시간 구간의 양 끝점
* opacity duration var : 불투명도가 감소하는 속도를 결정하는 파라미터

## 3. Training Scheme
학습에 포함할 프레임의 범위를 점진적으로 증가시킨다.
이전 Keyframe의 움직임 정보를 바탕으로 새로운 위치와 회전 초기화한다. 즉, 이전에 학습한 움직임 정보를 활용한다.
*N3V의 기본설정 값(progressive step) : 1 = interval 10 => 10씩 확장*
Ex) 학습 시간 범위 확장 iteration 주기가 400이고, 간격이 10이라면 
-> iter ~ 400 = 0~10 학습 -> iter 800 = 0~20으로 확장


# Additional Notes & Study
---
1. SH 표현 관련
 SH는 alpha Blending으로 관찰 방향에 따른 밝기 표현 가능. 하지만 조명 자체의 변화에 대해서 표현하기 어려울 수 있음. 즉, Gaussian 자체의 SH 색상이 바뀌는 건 아님. --> 예를 들어, 앞쪽 Opacity 정도에 의해 최종 픽셀 색상 RGB가 변화할 수 있음.

2. 학습범위와 key frame의 관계
	- 0~30  .: G1 Dynamic 전환 -> G1의 Keyframe별 위치, 회전 초기화
	- 0~100 : G1 학습 진행 & G2 Dynamic 전환 -> G2의 Keyframe별 추가 학습
	- 0~200 : G1, G2의 Keyframe별 위치, 회전 최적화
	- 0~300 : 전체 시간 범위에 대해 학습 진행
	-  .PLY   : 남아 있는 G1, G2 등의 Keyframe별 위치, 회전 기록


3. Keyframe & non-frame
Keyframe 파라미터에서 보간으로 중간 이미지 보간 --> GT 비교 --> Keyframe 파라미터 수정
