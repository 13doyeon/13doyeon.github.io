# Ex4DGS Compression Research with EGGS

> [[2026-11-14-eggs|EGGS]]의 encoding 과정과 MLP 기반 속성 표현을 [[2026-11-10-ex4dgs|Ex4DGS]]의 정적/ 동적 Gaussian에 단계적으로 적용하는 4D Gaussian Compression.

# Ideas
---
본 연구의 핵심은 Ex4DGS Parameter를 단순히 Static Gaussian/ Dynamic Gaussian으로만 구분하는 것이 아니라, **시간 불변 속성을 분리하여 압축**하는 것이다.


# Ultimate Goal
---
*구체적 실험 순서는 다음과 같다. 추후 변경 가능*
1. EGGS의 encode() 적용
2. Static Gaussian의 시간 불변 파라미터 표현 변경
3. Static Gaussian의 MLP 적용
4. Dynamic Gaussian의 시간 불변 파라미터 표현 변경
5. Dynmaic Gaussian의 MLP 적용

전체 연구의 최종 범위다.

하지만 모든 단계를 한 번에 구현하지 않는다.
우선순위는 **정적 Gaussian의 압축 가능성을 검증**하는 것이다. Dynamic Gaussian과 MLP 적용은 Static Gaussian 실험이 안정적으로 완료된 후 확장 단계에서 진행한다. 

또한 MLP 적용으로 인한 구현 복잡도나 학습 불안정성이 지나치게 큰 경우, 3단계와 5단계를 제외하고 property representation과 Quantization기반 압축까지만 수행하는 방법도 고려한다. 


# Experimental Plan
---
## Stage 1
**EGGS의 `encode()` 과정 적용**

적용 대상
```
EGGS에서 가져올 기능
├─ FP16 ↔ uint16 변환
├─ Morton 순서 계산
├─ G-PCC 압축 및 복원
├─ Huffman encoding 및 decoding
├─ FP16 codebook 저장
├─ MLP 파라미터 FP16 저장
└─ LZMA 최종 패키징
```

```
Ex4DGS 파라미터 추출
→ encoding
→ 압축 파일 생성
→ decoding
→ Gaussian 파라미터 복원
→ 렌더링
```

## Stage 2
**시간 불변 파라미터 표현 변경**

Ex4DGS Static Gaussian Parameter
```
Static Gaussian
├─ _xyz
├─ _xyz_disp
├─ _features_dc
├─ _features_rest
├─ _scaling
├─ _rotation
└─ _opacity
```

시간에 따라 위치를 변화시키는 파라미터 `_xyz_disp`를 제외하고, 나머지 속성 표현을 변경한다.

```
Static Gaussian i
├─ Canonical xyz
├─ Static local feature
├─ DC base
└─ Scale base
```
